# ブラウザドラムマシン

Web Audio API で Kick、Snare、Closed Hi-Hat、Open Hi-Hat を合成する 4 トラックのステップシーケンサーです。Vanilla JavaScript の ES Modules で動作し、音源ファイル、外部ライブラリ、ビルド、バックエンドは不要です。

## 操作方法

1. BPM、拍子（3/4・4/4・5/4・7/4）、小節数（1・2）を選びます。各拍は 4 ステップです。
2. ステップをタップして発音をオン・オフします。長押しでアクセントを付け、もう一度長押しすると通常音に戻ります。「アクセント編集」をオンにするとタップでアクセントを編集できます。キーボードでは Tab で移動し、Enter または Space で切り替え、Shift + Enter でアクセントを編集できます。
3. 「再生」でパターンを繰り返します。下辺が白い列が現在のステップです。再生中もパターンと音色を編集できます。狭い画面では各小節を横にスクロールできます。
4. 各トラックの Level・Tune・Decay を調整し、「試聴」で確認します。Mute は Solo より優先されます。Solo を設定すると、Mute されていない Solo トラックがパターン再生の対象になります。「音色をリセット」は Level・Tune・Decay を初期値に戻します。
5. 「消去」でトラック単位、「全消去」で全トラックのステップを消せます。拍子や小節数を縮めると範囲外のステップが隠れ、再び広げると表示されます。

Swing は隣接する 16 分音符 2 つの時間配分です。50% で均等、66.7% でほぼ 2 対 1 となります。通常音のベロシティは 80、アクセントは Accent Velocity で設定します。

## 書き出しと保存

| 形式 | 内容 |
| --- | --- |
| MIDI | SMF Format 0、480 PPQN、チャンネル 10、GM ドラムノート。テンポ、拍子、Swing、ベロシティ、Mute / Solo を反映し、小節境界で終わります。DAW でドラム音源のトラックに読み込んでください。 |
| WAV / Loop | 44.1 kHz・16 bit・ステレオ PCM。小節長を最も近いサンプル数に丸め、前の周期の余韻を織り込んで書き出します。 |
| WAV / With Tail | 同じ PCM 形式で、パターン長を確保したうえで音が残る場合はその余韻まで書き出します。 |
| JSON | パターンと設定を保存・復元できます。JSON の読み込みは現在の設定を置き換えます。 |

変更は同じブラウザーとオリジンの localStorage に自動保存されます。JSON にはスキーマバージョンが付きます。

## 内部設計

- `sequencer.js` がステップ数、Swing の時刻、ベロシティ、Mute / Solo を一元管理します。再生と両方の音楽ファイル出力がこのロジックを使います。
- `scheduler.js` は 25 ms ごとに AudioContext の時刻を参照し、100 ms 先まで発音を予約します。設定変更は未予約のイベントから適用します。ブラウザーによってバックグラウンドでタイマーが制限されると音が途切れる場合があります。スケジューラーの再開時は過ぎたイベントを飛ばし、ループの位相を保ちます。
- `audio-engine.js` と `instruments/` はリアルタイム再生と OfflineAudioContext で共用します。Closed Hi-Hat の発音時に Open Hi-Hat を短くフェードアウトさせます。音源ごとのゲインを抑え、同時発音用の余裕を確保しています。
- `state.js` と `storage.js` が初期値、読み込み時の範囲補正、スキーマ検証を担当します。破損した自動保存データがある場合は初期設定で起動します。

## ローカル実行とテスト

リポジトリのルートで次のコマンドを実行し、ブラウザーで `http://localhost:8000/drums/` を開きます。

```sh
python3 -m http.server 8000
```

Node.js 22.7 以降で、音声デバイスに依存しないテストを実行できます。

```sh
node drums/tests/drums.test.mjs
```

## GitHub Pages で公開

1. ルートの `index.html` と `drums/` を公開対象ブランチへ反映します。
2. リポジトリの **Settings → Pages** を開き、**Deploy from a branch** を選択します。公開ブランチ（このチェックアウトでは `master`）と **/(root)** を選んで保存します。すでにルートを公開している場合は公開ブランチへの反映で更新されます。
3. デプロイ完了後、サイトのトップページで「ドラムマシンへ」を選びます。ドラムマシンのパスは `/drums/` です。

[GitHub Pages の公開元設定](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
